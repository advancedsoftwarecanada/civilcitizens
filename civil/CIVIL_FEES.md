# Civil Fee Table

Use this file as the global fee reference for Civil Wallet and Civil Pay transaction fees.

## Updated Civil Fee Table

| Transaction Amount | Civil Fee |
| --- | --- |
| $0 - $100 | $0.50 |
| $100 - $200 | $0.75 |
| $200 - $300 | $1.00 |
| $300 - $400 | $1.50 |
| $400 - $500 | $2.00 |
| $500+ | $2.00 (max cap) |

## Notes

- Fees are charged in CAD.
- The fee is charged separately from the supported or purchased amount.
- The recipient receives the underlying transaction amount; Civil collects the fee.
- This schedule applies to Civil Wallet and Civil Pay flows that use the shared Civil fee helper.
